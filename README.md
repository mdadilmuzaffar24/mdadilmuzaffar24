### 🧠 Featured Projects

#### 🔹 AI Automated Financial & Ledger Agents
Autonomous AI agents built to fully automate financial data entry and bookkeeping workflows.
* **Tech Stack:** Python, LangChain, Google Workspace APIs, Pandas
* **Model Used:** Modern Large Language Models (LLMs)
* **Key Features:**
  * Secure data pipelines fetching unstructured invoices directly from Gmail and Google Drive.
  * Autonomous extraction of critical financial parameters from documents.
  * Dynamic, real-time maintenance of balance sheets and ledgers in Google Sheets.

#### 🔹 Interpretable Deepfake Detection Framework *(M.Tech Research)*
An advanced research framework (currently under IEEE review) leveraging Transfer-Learned CNNs to identify manipulated media.
* **Tech Stack:** Python, TensorFlow/PyTorch, OpenCV
* **Model Used:** Transfer-Learned Convolutional Neural Networks (CNNs)
* **Key Features:**
  * End-to-end framework for media forensics.
  * Integrated Explainable AI (XAI) techniques to ensure trustworthiness.
  * Visual and mathematical transparency using **Grad-CAM** and **SHAP**.

#### 🔹 AI Document Chatbot (RAG Pipeline)
An intelligent document chatbot utilizing modern LLMs and vector databases to process and query text efficiently.
* **Tech Stack:** Python, Streamlit, LangChain, Vector Databases, Groq API
* **Model Used:** Cloud-based LLMs
* **Key Features:**
  * Engineered Retrieval-Augmented Generation (RAG) mechanisms.
  * Highly accurate, context-aware responses reducing information retrieval time.
  * Deployed as a fully interactive, user-facing web application.

#### 🔹 Autism Spectrum Disorder Prediction
A diagnostic machine learning model aimed at the early detection of ASD using behavioral patterns.
* **Tech Stack:** Python, Pandas, Scikit-learn, SMOTETomek
* **Model Used:** XGBoost, Random Forest, Logistic Regression
* **Key Features:**
  * Advanced feature engineering and hyperparameter tuning.
  * Severe class imbalance handled seamlessly using SMOTETomek.
  * **Final Best Model:** XGBoost (CV ROC AUC: 0.96) prioritizing high recall for healthcare screening.
